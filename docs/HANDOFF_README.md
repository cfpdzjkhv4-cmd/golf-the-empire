# Golf: The Empire: handoff pack

Everything needed to start building the full game in Claude Code.

| File | What it is |
|---|---|
| `CLAUDE.md` | The brief Claude Code reads automatically: who you are, the stack, rules, milestones, and the asset pack requirements |
| `docs/DESIGN.md` | The full game design with every system and number from the prototypes |
| `docs/ASSET_PACK.md` | Art direction and delivery rules for the full asset pack |
| `docs/assets_manifest.csv` | Every asset the game needs (265 entries), with sizes, frames, priority and how Claude makes each one. Opens in Numbers or Excel |
| `prototype/prototype-5.html` | The working browser prototype. Open it in Safari on your Mac |
| `FIRST_PROMPT.md` | The message to paste into Claude Code to start |

## Getting started on your Mac
1. Install Xcode from the Mac App Store and open it once to finish setup.
2. Install Claude Code (see claude.com for current instructions).
3. Make a folder, for example `~/Projects/golf-the-architect`, and unzip this pack into it.
4. Open Terminal, `cd` into that folder, and run `claude`.
5. Paste in the prompt from `FIRST_PROMPT.md`.

You'll also need an Apple Developer account (£79 a year) before you can put builds on your iPhone through TestFlight or submit to the App Store. A free Apple ID is enough to run builds on your own phone while developing.
